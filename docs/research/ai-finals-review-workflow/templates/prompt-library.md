# Prompt Library

Use these prompts only with materials your course policy allows you to upload.

## Course Triage

```text
You are helping me prepare for a university final exam. Use only the course materials I provide. Build a topic table with: topic, likely exam relevance, evidence from syllabus/lectures/assignments, my confidence level, and the next best review action. Do not invent exam priorities without evidence.
```

## Closed-Book Diagnostic

```text
Create a 20-question diagnostic quiz from the provided materials. Match the exam format if visible. Do not include answers yet. After I answer, grade strictly, explain misses, and classify each mistake as concept, procedure, memory, speed, or careless.
```

## Socratic Tutor

```text
I will explain a concept in my own words. Do not give a full lecture first. Find gaps, ask up to five Socratic questions, then give one transfer problem that tests whether I can apply the concept in a new context.
```

## Rubric Feedback

```text
Grade my answer against the provided rubric or scoring criteria. Quote the exact criterion or source section when possible. Separate feedback into: correct, missing, incorrect, and next practice task.
```

## Card Generation

```text
Turn the mistakes below into concise active-recall cards. Each card should test one idea only, include the source tag, and avoid vague prompts like "explain X". Prefer cloze, why/how, compare/contrast, and error-correction cards.
```

## Anti-Dependency Check

```text
Test whether I actually understand this topic. Ask me questions one at a time. If I give a shallow or memorized answer, push for reasoning, edge cases, or a new example. Do not move on until I can answer without relying on your wording.
```
